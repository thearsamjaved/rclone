Personal Rclone Drive Client

This is the home page of a private Google OAuth client operated by Arsam Javid. It exists so that rclone, an open-source command-line tool, can access the owner's own Google Drive from a personal Linux computer.

What the app does

  • Authenticates with Google using OAuth 2.0 so rclone can reach Google Drive.
  • Lists, uploads, downloads, syncs and backs up files between the owner's Linux machine and the owner's Google Drive.
  • Runs entirely on the owner's computer. There is no server, website backend, or database behind this app.

Who it is for

This client is for personal use by its owner only. It is not offered as a service to the public, is not sold, and does not collect data from other people.

Google user data

Data accessed through Google APIs stays between Google's servers and the owner's own computer. It is never shared, sold, or sent to any third party. See the Privacy Policy for details.
