Privacy Policy

Last updated: October 27, 2026

This policy describes how the Personal Rclone Drive Client ("the app"), operated by Arsam Javid ("I", "me"), handles data. The app is a Google OAuth client used only by its owner to let rclone access the owner's own Google Drive from a personal Linux computer.

1. Data the app accesses

When authorized, the app may access, through the Google Drive API:

  • Files and folders in the authorizing user's Google Drive, including names, contents, sizes, timestamps and other metadata.
  • Basic account information required by Google's OAuth flow.

2. How the data is used

Google user data is used solely to provide the app's user-facing features: listing, uploading, downloading, syncing and backing up files between the owner's computer and the owner's Google Drive, as directed by the owner through rclone commands.

3. Storage

  • OAuth access and refresh tokens are stored locally on the owner's computer in the rclone configuration file (normally ~/.config/rclone/rclone.conf).
  • Files are transferred directly between Google's servers and the owner's computer.
  • No data is stored on any server operated by me. This website is static and does not collect anything.

4. Sharing

Google user data is not sold, rented, shared with, or transferred to any third party. It is not used for advertising, analytics, profiling, or to train machine-learning or AI models.

5. Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

All communication with Google uses HTTPS. Tokens stay on the owner's computer, which is protected by the owner's own account and disk security. The rclone configuration can additionally be encrypted with a password.

7. Retention and deletion

Access can be revoked and local data deleted at any time by:

  • Removing the app's access at myaccount.google.com/permissions.
  • Deleting the remote with rclone config delete <remote-name> or deleting the rclone configuration file.

8. Website

This website is hosted on GitHub Pages. It uses no cookies, analytics or tracking scripts. GitHub may log standard request information as described in the GitHub Privacy Statement.

9. Changes

Any changes to this policy will be posted on this page with an updated date.
